# timeseries-evaluation

Domain evaluation skill for time series forecasting.

## Trigger
Use when defining metrics, evaluation protocols, backtesting strategies, or experiment design for forecasting.

## What it provides
- Metric selection guidance (MAE, MSE, MAPE, sMAPE, MASE, CRPS, coverage)
- Scale-dependent vs scale-free tradeoffs
- Probabilistic forecasting metrics
- Baseline comparison rules
