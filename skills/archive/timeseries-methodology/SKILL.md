# timeseries-methodology

Domain methodology skill for time series model discovery.

## Trigger
Use when the task involves classical time series models, ARIMA/SARIMA, exponential smoothing, or establishing baselines for forecasting.

## What it provides
- Methodology guidance for classical model selection
- Baseline protocol (naive, seasonal naive, classical)
- When to use classical vs ML vs deep learning
