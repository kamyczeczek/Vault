Review: pstack-lite & skill self-selection in ARL

1. What was built (plain language)

  1. skills/poteto-mode-lite/ (SKILL.md): A minimal, pstack-inspired workflow orchestration skill adapted for Python (pytest, python) and PowerShell execution environments. It defines four core playbooks (investigation, bug-fix, feature, refactor) and the prove-it-works verification rule (requiring concrete verification matched to what changed rather than relying on "build passed"). Stamped in skills/MANIFEST.md.
  2. Upgraded skill_router.py: Replaced the static single-regex matcher with a three-phase self-selection router adhering to lab principles:
  • Decompose (ICM Architect style): Splits tasks into sequential steps.
  • Select (Unlazy style): Picks the most fitting skill/playbook from the catalog per step.
  • Iterate (Ralph Loop style): Emits a per-step plan with a stamped handoff line (what / state / next) ready for runner resumption.
  • Preserves the CLI contract (python skill_router.py "<task>") and provides route_task_verbose(task) for programmatic usage and testing.
  1. New Tests (tests/test_skill_router_selfselect.py): Tests-first verification covering poteto-mode-lite structure, manifest inclusion, verbose routing structure, and accurate skill self-selection across 4 sample tasks (bug-fix, feature, literature search, refactor).

3. What is open / what needs a human

  • Full multi-model interrogation (/interrogate): The lite mode focuses on single-agent playbook execution and deterministic testing; integrating automated multi-model code review arbitration remains optional.
  • Ralph integration binding: The verbose router emits Ralph-compatible handoff structures; running these steps under full Ralph multi-session control can be adopted for heavier autonomous runs.
  • Human Review: Human review of the routing outputs and playbook steps before committing or integrating into broader agent pipelines.
