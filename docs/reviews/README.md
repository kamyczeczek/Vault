# docs/reviews/ — audit reports

Workspace-level audit reports. `CLAUDE.md` declares this directory; the root gate
(`scripts/check_workspace_integrity.py`) fails on any file here that does not
carry exactly one `<!-- audit:begin -->` / `<!-- audit:end -->` pair
(R13 → `scripts/audit_agents_md.py --report-check`).

## The contract for a report in this directory

1. **Put the measurement in the block.** Between the two markers goes
   `scripts/audit_agents_md.py`'s own output — verbatim, generated:

   ```
   python scripts/audit_agents_md.py --write-block docs/reviews/<file>.html
   python scripts/audit_agents_md.py --report-check docs/reviews/<file>.html   # gate form
   ```

2. **Do not type a live number in prose.** The block's last section emits the
   derived sums (retireable total, coverage sum) precisely so a report can state
   a total without adding it by hand. A number in prose is a number nobody
   re-derives; that is the defect the whole workstream exists to remove (the
   review withdrew "35", then "~610 lines", then "22 evidence", then "18").

3. **Label what the gate cannot check.** Claims about *withdrawn* figures — a
   range's length, what an earlier version said — are arithmetic on prose, not
   output from a script. Write what they are, next to them.

4. **Regenerate, never retype.** `--write-block` is the only writer. It writes
   LF (matching `.gitattributes`), so a regeneration does not produce a
   whole-file diff.

5. **`render()` no longer emits trailing spaces**, because this output is
   committed verbatim: a gate whose own output needs a whitespace exemption to
   land in the repo is a gate that will eventually be exempted.

## The prose half

R13's second gate (`--report-check`) reads the block between the markers and
nothing else, so it could pass a report whose prose contradicted the block it was
sitting next to — v7 said "AGENTS.md is 137 lines" in four places while the block
beside it said 140, and regenerating the block is what made the document green.
The third gate closes that:

```
python scripts/audit_prose_numbers.py --list   docs/reviews/<file>.html  # what is unclassified
python scripts/audit_prose_numbers.py --by-value docs/reviews/<file>.html  # group it, to write entries
python scripts/audit_prose_numbers.py --check  docs/reviews/<file>.html  # exit 1 if unclassified
```

Every numeric token in the prose must be one of three things:

1. **emitted by the block** — re-derived from `AGENTS.md` on every run;
2. **a named shape** — a badge, a `:76-98` reference, `v7`, an ISO date, `R13`,
   `4 step 1`, `phase-5`, a `2 → 3` rewrite, a single-token `<code>` name;
3. **listed in `EXEMPT`** (`scripts/audit_prose_numbers.py`) with a class *and* a
   reason.

The check is bidirectional: an `EXEMPT` entry the report no longer needs is a
failure too, so the table cannot accumulate dead rows the way a report
accumulates stale prose. `--by-value` is how you add one — run it, read the line
numbers, write the reason.

Two limits worth stating, because a gate that hides them is worse than none:

- An entry may carry several classes. `50` is `35 + 15 = 50` on two withdrawn
  figures at one line and `51 − 1 = 50` in a mutation row at another; forcing one
  class on it would be a false claim in the table.
- `quoted-ags-evidence` covers figures quoted out of `AGENTS.md`'s own evidence
  bullet. `--check` catches that line being deleted, **not** its figures being
  edited. A quote of it rots until someone re-reads the file, and the gate cannot
  close that.

## Live Audit Reports (Block + Prose Regenerated Together)

Audit reports in this directory are **live** documents: the extracted metrics block (`--write-block`) and the surrounding prose numbers (`audit_prose_numbers.py`) are regenerated and checked together. Neither half is static; whenever source files change, reports are re-derived so that prose and numbers never drift apart.

## What is still ungated here

- **This README.** No gate checks that a new `*.html` gets a row in the table
  below. Adding one is a manual step, and the next revision will not remind you.
- **The prose itself** — sentences, claims and judgements. Rule 1 keeps the
  arithmetic out of it; nothing keeps it honest.
