## 11. Minimum test set for a retrieval improvement (answer)
For any proposed retrieval change R (e.g., adding graph expansion):
1. **Baseline run** without R on the frozen question set, score recorded (B0.1-style).
2. **Ablation run** with R on the same set; delta on target dimension (recall/grounding) on observable outputs.
3. **Negative control**: an R variant engineered to be irrelevant (e.g., expansion on a tag set with no intersections); score must not improve (dead-improvement detector).
4. **Counterfactual check**: on questions where R *cannot* fire (zero graph neighbors), scores must equal baseline — isolation of R's effect.
5. **Root-cause attribution**: if a dimension regresses, identify which claim class broke before attributing to R; correct only that class (oracle discipline).
Promotion only when 1–5 pass with ≥2 dimension gains and no integrity regression (scorecard promotion rule).
