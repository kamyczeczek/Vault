# Reflection: S-41 Design — RFF-MoE Frontier Probe

**Date:** 2026-09-13
**Context:** S-26 incumbent (1.9909 MAE / 2.4710 RMSE); S-39 and S-40 rejected for linear-only diversity ceiling.

## Why S-41

S-39 proved that adding more linear experts (NLinear/RLinear/Fourier-lag) with EWA routing cannot beat S-26: all experts share the same linear readout on anchored windows, so the pool collapses to a weighted linear combination of the same basis. S-40 showed calendar features collapse in linear members (calendar-NLinear = no-calendar NLinear). S-35 showed that non-linearity on deltas fails (val 3.12–3.17 ≫ 2.89).

S-41's hypothesis: **the frontier gap is not more linear experts, but a non-linear feature map that preserves raw window information**. RFF provides exactly this: a deterministic, fixed, kernel-approximate projection of the raw window into a high-dimensional space, where a simple linear readout can capture non-linear temporal structure.

## Design Rationale

| Decision | Rationale |
|----------|-----------|
| RFF on raw window (not deltas) | S-35 scar: RF on deltas failed because deltas lose absolute level information; raw window preserves it |
| RFF on raw window (not anchored) | RFF is rotation-invariant to mean shifts; anchoring would add noise |
| Calendar features in RFF expert (not linear) | S-40 scar: calendar-linear collapsed to OT-only; RFF can exploit calendar-raw interactions |
| Uniform router | S-39 EWA instability + S-36/S-38 learned gating regime fragility |
| Keep S-26 2 linear experts | Proven base; provides linear anchor for the ensemble |
| D=500 RFF | Moderate capacity: enough to capture structure, small enough for fast Ridge |
| Fixed seed 42 | Determinism required for protocol-clean runs |

## Risk Assessment

1. **RFF capacity risk:** D=500 may still be too small to capture complex non-linearities in 336-dim window → test MAE may not improve. Mitigation: if S-41 fails, next probe should increase D or try multiple RFF seeds.
2. **Calendar-overfit risk:** Calendar features are horizon-broadcast and may overfit validation seasonality. Mitigation: transfer guard (±0.02) catches this.
3. **Runtime risk:** RFF projection + Ridge on D=500 for 2161 origins may exceed 300s. Mitigation: D=500 is moderate; if slow, reduce to D=256.

## Stop Condition

If S-41 fails (MAE ≥ 1.9909 or disjoint-4 > 1.9696), the univariate OT + calendar frontier under S-20-clean protocol is **exhausted for linear-pool + simple non-linear readout** architectures. Next gains require:
- Exogenous channels (S-34 multivariate path, but with sparse regularization)
- Protocol change (longer horizon, different dataset)
- Neural non-linear models (PatchTST, TFT) outside the current linear-pool paradigm
