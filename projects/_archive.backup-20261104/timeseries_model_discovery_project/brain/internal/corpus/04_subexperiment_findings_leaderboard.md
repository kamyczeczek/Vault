## Sub-Experiment: Volatility-Gated / Regime-Conditional Dynamic Weighting (S-36) — REJECTED
- **Directory**: `sub_experiments/volatility_gated_s36/` (re-run: `python sub_experiments/volatility_gated_s36/rolling_arm.py`; evidence: `results_s36.json` + `harness.log`).
- **Lane**: MEDIUM — frontier bet #3 (volatility-conditioned dynamic weighting over S-26 members).
- **Protocol**: S-20-clean (members frozen train 8545 for val search, refit 11425 for frozen test; chronological validation search n2=1080/1081, 11-α grid [0.1..30000], disjoint-4 diagnostic, W4 stability cap 1.8427 = S-20 6-member leaderboard W4, **NOT the defended S-26 incumbent whose in-harness W4 = 1.9579**). Base pool 6 diverse linear members [NLinear L96 a1, L336 a1/a10, L720 a1, DLinear L96 k25, L336 k25]; incumbent subset [L336 a1 + a10] (S-26) is the pooled baseline.
- **Gate design**: continuous macro-volatility gating. Per-origin volatility scalar `v_t = std(history[t-L:t])` (L in {96,336,720}, TRAIN-standardized via train-only mu/sd — global window scale per S-04, NOT kNN distance per S-23 scar) and trend scalar `delta_t = mean[t-L:t]-mean[t-2L:t-L]` (level-free). Gated stack augments the 2-member S-26 blend with one extra feature per origin: `z_t * D_t` (volatility-modulated diverse spread `D = P_L96 - P_L336`, mean |D|=0.74) or `z_t` broadcast (scalar bias), learned per-horizon via Ridge with per-column diagonal penalty `(a_blend, a_gate)` — entropy-regularized (shrinkage toward uniform, `a_gate` grid [100..10000]), orthogonal to S-19 simplex argmin. `z==0` collapses exactly to the static S-26 stack.
- **Key diagnostic — why naive S-26 gating is degenerate**: the S-26 pair `[L336 a=1 + a=10]` is 99.99% correlated (mean |D|=0.00029, std 0.00037); `z*D` has std 0.0004 — numerically invisible to Ridge at α=10k (all 7 gated variants on the pure S-26 pair collapse to pooled: held-out delta exactly 0.0000, full 2161 1.9909). The diverse spread `D_L96_L336` (0.74) is required for any detectable gate signal, yet S-04/S-32 already showed per-horizon Ridge spans window-scale.
- **Findings**: **REJECT — two regimes of failure.**
  - (a) *Pure S-26 gating (z*D_internal)*: collapses to static (delta 0.0000) — no capacity. S-26 pair has no disagreement to gate.
  - (b) *Diverse-spread / bias gating (z*D_ext, z broadcast) with per-column Ridge*: 2/7 variants beat pooled on held-out (best `vol720_bias` held 2.5113 vs pooled 2.5191, −0.0078; `vol336_Dext` −0.0038) but **all catastrophically fail frozen-test transfer**. Winner `vol720_bias` (a_blend=3000, a_gate=300) held-out win +0.0078 → frozen test **full 2.4724 (+0.4815 vs S-26 1.9909), disjoint 2.5975 (+0.6279), W4 2.7907 (≫ cap 1.84)**. The vol distribution shifts val→test by −0.48 to −0.90σ (test volatility systematically lower), so the gate coefficient learned on val's volatility regime extrapolates out-of-distribution on test. Orthogonality diagnostics confirm the gate is not noise-fitting via kNN distance (`corr(z,|D|_mean)` 0.001–0.27, low) and not collapse via simplex (mean weight entropy 86–91% of max, not corner solution) — the failure is **domain shift in the conditioning variable v_t itself** (S-04 macro-volatility is regime-specific).
  - Pooled 6-member all-linear `a=3000` held 2.5644 (vs S-26 2.5191) — no diverse-pool baseline helps; S-26 pair remains the val-optimal subset.
- **Why not closed by S-23/S-19 scars, but orthogonal and still rejected**: S-23 (kNN distance) and S-19 (simplex) scars are avoided by construction (continuous global scale, per-horizon Ridge + entropy regularization). S-36's new failure mode is **val→test volatility-regime shift** — the conditioning variable's distribution shifts, making the gate non-stationary. This is consistent with H2 saturation: no per-window scalar of the univariate OT history adds orthogonal signal beyond the L336 linear combination.
- **Val→test transfer guard**: held-out gain does NOT transfer (pooled always wins frozen test). No SOTA promotion; S-26 1.9909/2.4710 incumbent preserved.

## Data processing pipeline (`data.py` — single source of truth)
1. **Load raw** — `ETTh1.csv`, 17,420 hourly rows (2016-07-01 00:00 → 2018-06-26 19:00), file order == time order. No resampling/interpolation; the series is gapless.
2. **Validate** — OT column must be finite, 1-D, expected length; else hard error.
3. **Split (time-based, chronological, no shuffle/overlap)** — `make_split()` writes `train.csv` (raw rows 0–11424: train 8,545 + validation 2,880) and `test.csv` (raw rows 11425–14224). Raw rows 14225+ are unused reserve. `ProtocolData.load()` verifies the split files against the raw file on every load and errors if out of sync.
4. **Forecast views** — locked H=720: `forecast_views()` fits on all of `train.csv` (11,425) and scores against `test.csv[:720]` (the t=0 anchor / legacy view); `rolling_views()` exposes the frozen fit history + eval series for rolling-origin scoring.

Regenerate split files: `python data.py`. All sweeps load via `data.py` accessors — identical split everywhere.
