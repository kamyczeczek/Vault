Now more in depth!

👇👇

1. ﻿﻿﻿Discovery (the fun part): You talk to an Al to define the goal, which is saved as an '[intent.md](http://intent.md/)' file.
2. ﻿﻿﻿Spec Generation (more intentional and specific ofc): The Al automatically creates a technical plan ('[spec.md](http://spec.md/)") based on that intent.
3. ﻿﻿﻿Build Mode (monitor this and understand for first time users): The Al uses the spec to write code and create a '[plan.md](http://plan.md/)'. Multiple Al agents can work on different tasks simultaneously using git branches.
4. ﻿﻿﻿Test Phase: The Al runs all tests and checks automatically to ensure nothing is broken.
5. ﻿﻿﻿Deployment: The Al creates a pull request for human review, following strict security and governance rules.
6. ﻿﻿﻿Maintenance: The Al monitors the live system. If an error occurs, it detects the problem, creates a new

'[intent.md](http://intent.md/)', and begins the cycle again.
