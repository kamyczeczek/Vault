# Reflection Architecture: `.md` as the Durable Layer

**Status:** decision record (2026-09-30). Implements the workspace rule *"every change must be visible in a markdown file"* (`175_icm_knowledge_big`) and the bounded-persistence rule from `00_reflection_reorientation_cost`.

## Problem

agentmemory (`@agentmemory/agentmemory` v0.9.29) ships in **zero-LLM mode**:
auto-capture (observations) and BM25/local-embedding recall work, but every
durable distillation tier — session summarization (`mem::summarize`),
episodic→semantic consolidation, knowledge-graph extraction — is a **no-op
without an LLM provider key**. Its KV tiers are also opaque: not git-tracked,
not inspectable, not FTS5-indexed. Snapshot, consolidation, and slots are
opt-in and default off.

## Decision

Two layers, cleanly separated:

| Layer | Store | Role | LLM needed? |
|---|---|---|---|
| **Capture** (working/episodic) | agentmemory KV + `state_store.db` | Auto-observed prompts/tools/results; cross-session recall; scars | No |
| **Durable reflection** | **`.md` files** in `reflection/` | Distilled lessons, candidates, digests, accepted rules with eviction predicates | No (distilled by the ICM reflection pass) |

**Durable value is produced by writing markdown, not by the KV tiers.**
agentmemory remains the sensor; markdown is the memory.

## Why `.md` (graph-justified)

1. **Re-orientation cost** (`00_reflection_reorientation_cost`): growing
   un-indexed files fail; the verified repair is *bounded state + query*.
   Our `.md` layer is bounded (hard line caps) and queryable (FTS5 via
   `knowledge/graph`), never re-read whole.
2. **ICM visibility** (`175_icm_knowledge_big`): every durable change must be
   visible in a markdown file → diffable, git-trackable, reviewable.
3. **Rule of scars** (`reflection_rule_of_scars`): failures are compiled to
   failure triples (failed state / cause / fix) and stored as `.md` entries,
   so blocked states stay blocked (monotonicity).
4. **Lesson eviction** (`00_08_lesson_persistence_eviction_requirement`,
   `vera-expa-002`): each accepted `.md` rule in `reflection/memory.md`
   encodes its own eviction predicate; reflection reads/writes `.md`, not KV.

## Permanent agentmemory configuration

`~/.agentmemory/.env` is the documented, restart-safe mechanism
(`agentmemory init` + provider key). Generated by
`scripts/configure_agentmemory_env.py`, which reuses the machine's
OpenAI-compatible router (pi `models.json` → provider `nara`,
`https://router.bynara.id/v1`, free models) so no paid key is required:

```ini
OPENAI_API_KEY=<nara router key>     # auto-filled, 0600 perms
OPENAI_BASE_URL=https://router.bynara.id/v1
OPENAI_MODEL=nex-n2.5-pro
SNAPSHOT_ENABLED=true                # rollback protection before consolidation
CONSOLIDATION_ENABLED=true           # 4-tier pipeline live
AGENTMEMORY_SLOTS=true               # fixes the HTTP 500 on slots
GRAPH_EXTRACTION_ENABLED=true        # LLM-backed graph extraction
```

Restart to load: `agentmemory stop --force` then `agentmemory` (worker).
Verified live: `mem::summarize` circuit-breaker was open with
`failureCount: 3, successCount: 0` (no provider) before this fix.

## The `.md` reflection loop

```
pi session JSONL (~/.pi/agent/sessions/...)        agentmemory observations
        │  scripts/export_session_reflection.py          │ (capture, no LLM)
        ▼                                               ▼
reflection/sessions/<date>_<id>.md   (bounded ≤90 lines, candidate status)
        │  ICM reflection pass (pipeline/06_reflect)
        ▼
reflection/candidates/*.md  →  reflection/digests/*.md  →  reflection/memory.md
        │                                                            │
        └──── distill; each accepted rule carries an eviction predicate ────┘
                     │ FTS5 index (knowledge/graph/build_graph.py)
                     ▼
              query-over-read: recovery is a graph query, never a file scan
```

- **Exporter contract** (`scripts/export_session_reflection.py`, stdlib-only,
  idempotent): intent (≤200 chars), top tools/files, error failure-triples
  (≤8 × 150 chars), fixed distillation questions, eviction predicate,
  **hard cap 90 lines**. One file per session id; re-export overwrites.
- **Decay**: superseded files move to `reflection/stale/` (existing dir),
  keeping the reflection root bounded.

## Gaps this does NOT solve (scarred, do not retry)

- agentmemory `mem::summarize`/consolidation quality depends on the
  `nara` router's model competence; if summaries regress, the `.md`
  layer is unaffected (decoupled by design).
- `memory_slot_list` HTTP 500 is fixed only after worker restart with
  `AGENTMEMORY_SLOTS=true`; re-probe after restart before building
  automation on slots.

## Hill-climbable goal (measurable)

- **G2 groundedness ≥ 80%**: after one restart + `memory_consolidate`,
  verify ≥ 80% of promoted `.md`/KV lessons have a resolvable `Evidence:`
  id (graph chunk or session id) via `knowledge/graph/ask.py`.
- **G4 sublinear growth**: `reflection/memory.md` line count grows ≤ O(log n)
  across sessions because eviction predicates fire (checked by
  `scripts/evict_stale.py`).
