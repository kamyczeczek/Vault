# Chief of Staff Crew

A small team of agents for Claude Code. One chief of staff that reads the work, finds the problems and routes each one to the specialist who owns it. Four specialists: a designer, a copywriter, a builder and an auditor. Each owns its own files. The auditor checks everyone and fixes nothing.

No installs, no API key. Five text files do all of it.

## Try it

The repo ships with a practice site, a record shop page with several things wrong with it. The demo is an example, nothing more: the crew is general and the site is just something to watch it work on.

1. Clone this repo, open a terminal in the folder, and run `uv run --no-project --with pillow python tools/make_hero.py` once. It creates the deliberately huge photo the auditor is meant to catch.
2. Run `claude --agent chief-of-staff` and accept the trust prompt.
3. Type: `fix the Vinyl Room site`

Then watch. The chief reads the site, lists what it found, sends out all four specialists in parallel and collects their reports. A few minutes later the page is rebuilt. Refresh `site/index.html` in your browser to see it.

Want the live flow board from the video? `python serve.py`, then open `http://127.0.0.1:8795/board/index.html`.

## Make it yours

This is the part that matters. **The agents are generic. Everything specific lives in `CLAUDE.md`**, the house file, which every agent reads:

- your palette, type and design rules
- the real facts of your business, so nothing gets invented
- the layout constraints
- the table of who owns which files

Point the crew at your own project by replacing the facts, the rules and the ownership table in `CLAUDE.md`. The five agents stay as they are. If the output is not to your taste, sharpen the house file, that is the steering wheel.

Two dials worth knowing in each agent file: `model` sets the quality and cost of that seat, and `maxTurns` caps how long it can run.

The demo folder is preconfigured to run without permission prompts (`.claude/settings.json`). Delete that file if you would rather approve each step.

## The shape

```
CLAUDE.md            the house file. Edit this one.
.claude/agents/      chief-of-staff, designer, copywriter, builder, auditor
.claude/settings.json
site/                the practice site (the example)
board/  serve.py     the live flow board (optional)
tools/               a small image shrinker the auditor uses
```

# The Vinyl Room

An independent record shop's website. The site is in `site/`.

| File | What it is | Who owns it |
|---|---|---|
| `site/index.html` | markup and the page's words | the copywriter |
| `site/style.css` | how it looks | the designer |
| `site/art.svg` | the page's artwork | the designer |
| `site/main.js` | what happens when you click | the builder |
| `site/hero.jpg` | header photograph | the auditor |

## The shop, as it really is

Use these facts. Never invent a detail about this business.

- The Vinyl Room, 14 Gloucester Road, Bristol, BS7 8AT.
- Open Monday to Saturday. Weekdays 10am to 6pm, Friday until 8pm, Saturday 9am to 8pm. Closed Sunday.
- New pressings, classic reissues, hand graded secondhand. Jazz, soul, post punk, dance.
- Two listening booths at the back, free, first come first served, bookable in advance.
- Special orders take about a week.

## How this page is shown

It is displayed in a **wide, short window, about 1080 by 520**, and **the whole page must fit on that one screen with no scrolling**. Compose it like a gig poster, not a document:

- A **left panel about a third of the width, full height, ink background** carrying the artwork large with the headline plate and strapline stacked under it.
- The **right two thirds** hold everything else as a tight grid of cards: about, hours, the order button. No card floats alone, no dead areas of empty ground.
- Fill the frame edge to edge. Big type, tight gaps (16 to 24px), everything anchored to the grid.
- Body sized to exactly the window: no margins collapsing into empty bands top or bottom.

## House style

**Look.** Neo brutalist and graphic. Flat blocks of colour, no gradients, no photographic softness. Every solid element carries a **4px black border** and an **8px hard offset shadow**, never a blur. Big confident type. Illustration over photography.

Palette, and only this palette:

| | |
|---|---|
| cream `#FFF6DF` | the ground everything sits on |
| ink `#111111` | all borders, shadows and body text |
| pink `#FF2D78` | the loudest accent, used sparingly |
| mint `#9BE7C4` | blocks and panels |
| blue `#4D8DFF` | blocks and panels |
| yellow `#FFD23F` | highlights and plates |

Body text is never an afterthought: **Rubik at weight 500 or heavier, 15px minimum, ink on a light ground**, with real space around it. Thin grey paragraph text is off style.

Headline type is heavy and geometric, ideally Archivo Black or Lexend Mega with a system fallback. Body type is Rubik or a plain sans. Monospace is JetBrains Mono.

Borrow the language of a gig poster: banner ribbons, cream label plates holding black type, bold arcs, a halftone dot texture, a headline where each word takes a different colour from the palette.

**Card anatomy, every card the same skeleton.** Content starts at the top of the card, never vertically centred, never a dead band above the heading. The heading is Archivo Black, small size, letterspaced uppercase, with a 3px ink underline the full width of the card. Below it, body text, then any control. Padding 20 to 24px all round, consistent across every card.

**Ink panels** are never flat black boxes: they carry a 4px cream border and an 8px pink offset shadow, and their text is cream.

**Tables** have an ink header band with cream uppercase letterspaced labels, 3px ink rules between rows, and data figures in the monospace face. No faint hairlines.

**Buttons** are Archivo Black uppercase on pink with the ink border and hard shadow, and press down by their shadow depth on hover.

**Words.** British spelling. **Never use a long dash.** Use a comma, a colon or brackets. No Oxford comma. No Latin abbreviations. Say the thing plainly and stop.

"""No-store static server so the board and the site always show the files as they are.

    python serve.py     then open http://127.0.0.1:8795/board/index.html

import functools
import http.server
import os

ROOT = os.path.dirname(os.path.abspath(__file__))


class _Handler(http.server.SimpleHTTPRequestHandler):
    def end_headers(self):
        self.send_header("Cache-Control", "no-store")
        super().end_headers()
http.server.ThreadingHTTPServer(("127.0.0.1", 8795),
    functools.partial(_Handler, directory=ROOT)).serve_forever()

function fitView(){
  const vp = el("viewport");
  if (!vp) return;
  const sc = Math.min(vp.clientWidth / 1080, vp.clientHeight / 520);
  el("view").style.transform = "scale(" + sc + ")";

function bossOn(text){
  el("g-boss").classList.add("on");
  if (text) el("boss-say").textContent = text;
}

function launch(lane){
  if (!st[lane] || st[lane].on) return;
  st[lane].on = true;
  const g = el("g-" + lane);
  const w = el("w-" + lane);
  const len = Math.ceil(w.getTotalLength());
  w.style.strokeDasharray = len;
  w.style.strokeDashoffset = len;
  w.classList.add("live");
  g.classList.add("on");
  setTimeout(function(){ if (!st[lane].done) g.classList.add("working"); }, 420);
}

function finish(lane){
  if (!st[lane] || st[lane].done) return;
  st[lane].done = true;
  const g = el("g-" + lane);
  g.classList.remove("working");
  g.classList.add("done");
}

const PRIMARY = {"style.css":"design","index.html":"words","main.js":"build","hero.jpg":"audit"};
function apply(ev){
  if (ev.kind === "read"){
    const f = ev.file || "";
    bossOn(/\.(html|css|js|svg|jpg|png|md)$/.test(f) ? "reading " + f : "collecting reports");
  }
  else if (ev.kind === "board") bossOn((ev.items || []).length + " problems found");
  else if (ev.kind === "spawn"){ bossOn("dispatching"); launch(AGENT[ev.who] || ev.lane); }
  else if (ev.kind === "edit"){
    const l = FILE[ev.file]; if (!l) return;
    launch(l);
    el("view").src = "/site/index.html?r=" + Date.now();
    if (PRIMARY[ev.file]) finish(l);
  }
}

async function poll(){
  try{
    const r = await fetch("events.jsonl?t=" + Date.now(), {cache:"no-store"});

"""Create the deliberately oversized header photo the auditor is meant to catch.

    uv run --no-project --with pillow python tools/make_hero.py
"""
import os
import random

from PIL import Image

out = os.path.join(os.path.dirname(os.path.dirname(os.path.abspath(__file__))), "site", "hero.jpg")
w, h = 4800, 3200
im = Image.new("RGB", (w, h))
px = im.load()
random.seed(7)
for y in range(0, h, 4):
    for x in range(0, w, 4):
        c = (random.randint(30, 90), random.randint(20, 60), random.randint(40, 110))
        for dy in range(4):
            for dx in range(4):
                if y + dy < h and x + dx < w:
                    px[x + dx, y + dy] = c
im.save(out, quality=98, subsampling=0)
print(f"{out}: {os.path.getsize(out) / 1048576:.1f} MiB")

"""Shrink an image in place, keeping it visually the same.

    uv run --no-project --with pillow python tools/shrink_image.py site/hero.jpg 1600
"""
import os
import sys

from PIL import Image

path = sys.argv[1]
longest = int(sys.argv[2]) if len(sys.argv) > 2 else 1600
before = os.path.getsize(path)
im = Image.open(path)
w, h = im.size
im.thumbnail((longest, longest))
im.convert("RGB").save(path, quality=82, optimize=True)
after = os.path.getsize(path)
print(f"{path}: {w}x{h} {before/1048576:.1f} MiB -> {im.size[0]}x{im.size[1]} {after/1024:.0f} KiB")

---
name: auditor
description: Auditor. Checks whether a site is sound: asset weight, load cost, dead links, accessibility. Reads everything, owns the image assets, and changes no code.
tools: Read, Grep, Glob, Bash
model: sonnet
maxTurns: 20
color: green
---

You are the auditor. You audit, and you do not write code.

FILE: .claude/hooks/board.py
================================================
"""Write one line to board/events.jsonl for every event the reel board draws.

PreToolUse on Agent gives the LAUNCH. PostToolUse on Agent gives the RETURN.
PostToolUse on TodoWrite and the edit tools give the board and the file changes.
Never blocks, never fails a tool.
"""
import json
import os
import sys
import time

ROOT = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
OUT = os.path.join(ROOT, "board", "events.jsonl")

OWNER = {
    "designer": "design",
    "copywriter": "words",
    "builder": "build",
    "auditor": "audit",
}


def emit(kind, **fields):
    row = {"t": round(time.time(), 3), "kind": kind}
    row.update(fields)
    os.makedirs(os.path.dirname(OUT), exist_ok=True)
    with open(OUT, "a", encoding="utf-8") as fh:
        fh.write(json.dumps(row, ensure_ascii=False) + "\n")


def main():
    payload = json.load(sys.stdin)
    event = payload.get("hook_event_name") or ""
    tool = payload.get("tool_name") or ""
    inp = payload.get("tool_input") or {}

    if tool == "Agent":
        who = inp.get("subagent_type") or ""
        if who in OWNER and event == "PreToolUse":
            emit("spawn", who=who, lane=OWNER[who])
        return

    if event != "PostToolUse":
        return

    if tool == "TodoWrite":
        todos = inp.get("todos") or []
        if isinstance(todos, str):
            try:
                todos = json.loads(todos)
            except Exception:
                todos = []
        items = []
        for t in todos:
            text = t.get("content") if isinstance(t, dict) else str(t)
            if not text:
                continue
            who = next((v for k, v in OWNER.items() if "(%s)" % k in text), "")
            items.append({"text": text.split(" (")[0], "who": who})
        emit("board", items=items)

    elif tool in ("Edit", "Write", "MultiEdit"):
        emit("edit", file=os.path.basename(inp.get("file_path") or ""))

    elif tool == "Read":
        name = os.path.basename(inp.get("file_path") or "")
        if name:
            emit("read", file=name)


if __name__ == "__main__":
    try:
        main()
    except Exception:
        pass
