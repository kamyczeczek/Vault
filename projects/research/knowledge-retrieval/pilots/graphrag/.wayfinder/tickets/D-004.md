# D-004: JSON schema planu/odpowiedzi + reguła confidence — RESOLVED (Phase 5 scope)

## Question

Jaka jest zamrożona schema `plan.json` (seed_kinds/relacje/glebokosc/
filtry/strategia) i `answer.md` (Odpowiedź/Dowody/Ślad/confidence), oraz
jaka reguła liczy confidence (wysoki/średni/niski) z liczby i jakości
dowodów — tak, żeby dowód dało się zweryfikować mechanicznie?

## Resolution (2026-10-10)

Schema zamrożona w `proof/produkt-x/plan.json` + `answer.md`:
- Plan: `seed_kinds`/`relacje`/`glebokosc`/`filtry`/`strategia` (walidacja
  w `waliduj_plan` — unknown relations -> error, głębokość>=1).
- Odpowiedź: sekcje `odpowiedz`, `dowody` (lista trójek), `pewnosc`
  (wysoka/srednia/niska), `uzasadnienie_pewnosci`, `slad_wykonania` (tablica
  wywołań narzędzi z parametrami), `plan` (echo planu).
- Reguła confidence: **wysoka** jeśli >=2 trójki tworzącą spójną ścieżkę,
  **srednia** przy 1 trójce, **niska** przy braku dowodów (odmowa). W
  dowodzie Fazy 5: 2 trójki -> wysoka.

Adversarial case (blizna metryk): losowe trójki bez pokrycia twierdzeń
są odrzucane przez `weryfikuj_twierdzenia` (rejected > 0 -> odrzucone).
Schema + confidence potwierdzone oracle-first: selftest PASS na przykładzie
ze speca.
